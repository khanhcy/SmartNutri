# CLAUDE.md — SmartNutri

## Project Overview

SmartNutri is a **Vietnamese nutrition-tracking mobile app** built with Flutter + Firebase, accompanied by a React admin web scaffold and Cloud Functions backend. All user-facing text is in Vietnamese.

| Component | Stack | Location |
|---|---|---|
| Mobile app | Flutter 3.x · Dart ^3.10.1 | `lib/` |
| Backend | Firebase (Auth, Firestore, Crashlytics, Storage) | `firebase.json`, `firestore.rules`, `storage.rules` |
| Cloud Functions | Node.js · TypeScript · Firebase Functions v2 | `functions/` |
| Admin web | React 18 · TypeScript · Vite | `admin-web/` |

**Firebase project:** `smartnutri-dev-2e67b` (configured in `.firebaserc`)

```bash
flutter pub get                   # Install dependencies
flutter run                       # Run on connected device/emulator
flutter test                      # Run all tests
flutter build apk --debug         # Build debug APK
```

### Firebase
```bash
firebase deploy --only firestore:rules,firestore:indexes   # Deploy rules & indexes only
firebase deploy --only storage                             # Deploy storage rules
firebase deploy --only functions                           # Deploy Cloud Functions
firebase deploy --only hosting                             # Deploy admin web (from admin-web/dist)
firebase emulators:start --only functions,firestore,auth   # Start local emulators
```

```bash
cd functions && npm install && npm run build
```

### Admin Web
```bash
cd admin-web && npm install && npm run dev
```

## Domain Models

### UserProfile (`profiles/{uid}`)
`uid`, `email`, `displayName`, `age` (int), `heightCm` (double), `weightKg` (double), `gender` (string), `activityLevel` (string), `onboardingCompleted` (bool), `updatedAt` (ISO 8601)

### NutritionGoal (`goals/{uid}`)
`calorieTarget` (int), `proteinG` (int), `carbG` (int), `fatG` (int), `targetWeightKg` (double?), `waterTargetMl` (double, default 2500), `updatedAt` (ISO 8601)
- Auto-calculated from profile via **Mifflin-St Jeor** TDEE equation
- Default fallback: 2000 kcal, 120g protein, 250g carb, 65g fat

### MealEntry (`users/{uid}/meal_entries/{id}`)
`uid`, `date` (YYYY-MM-DD string), `mealType` (breakfast|lunch|dinner|snack), `foodName`, `portionG`, `calorieKcal`, `proteinG`, `carbG`, `fatG`, `loggedAt` (ISO 8601)

### FoodItem (in-memory catalog in `FoodService`)
`id`, `name`, `calorieKcal`, `proteinG`, `carbG`, `fatG` (all per 100g), `category`, `defaultPortionG`

### DailyStats (`users/{uid}/daily_stats/{date}`)
Water intake tracking (via `WaterService`)

### WeightLog (`users/{uid}/weight_log/{date}`)
Weight history tracking (via `WeightService`)

## Firestore Structure & Security Rules

```
profiles/{uid}              → read/write: owner only
goals/{uid}                 → read/write: owner only
users/{uid}/meal_entries/{id}  → read/write: owner only
users/{uid}/daily_stats/{date} → read/write: owner only
users/{uid}/weight_log/{date}  → read/write: owner only
foods/{foodId}              → read: any authenticated user; write: denied (admin-only via backend)
workouts/{workoutId}        → read: any authenticated user; write: denied (admin-only via backend)
```

**Storage rules:** Any authenticated user can read/write (placeholder — should be tightened).

## Key Patterns

- **State management:** Provider (`context.read<T>()` for actions, `context.watch<T>()` for reactive UI, `StreamBuilder` for Firestore real-time streams)
- **Routing:** GoRouter with `StatefulShellRoute.indexedStack` (4 bottom tabs preserve state via IndexedStack). Auth gating via `AuthFlowNotifier` + `refreshListenable`.
- **DI:** All services registered in `bootstrap.dart` via `MultiProvider`. Services are plain classes (not ChangeNotifiers) except `RecentFoodsService` and `AppSettingsProvider`.
- **Environment:** `AppEnvironment` reads `--dart-define` flags `APP_FLAVOR` and `FIREBASE_PROJECT_ID`.
- **Food DB:** 120+ Vietnamese dishes hard-coded in `FoodService` (~22 KB). Not yet migrated to Firestore `foods` collection.
- **UI language:** All Vietnamese (labels, error messages, greetings, food names, meal types).
- **Theme:** Material 3, seed color `#2E7D32` (green), font "Be Vietnam Pro" via `google_fonts`. Light + dark mode supported, toggled via `AppSettingsProvider`.
- **Offline:** Firestore persistence enabled (unlimited cache size) + `OfflineBanner` wraps entire app in `SmartNutriApp.build()`.
- **Crashlytics:** Enabled in release mode; debug mode records non-fatal errors.
- **Notifications:** `flutter_local_notifications` with water & meal reminder toggles.

## Coding Conventions

- **File naming:** snake_case for all Dart files
- **Class naming:** PascalCase; services are `XxxService`, models are domain nouns (`UserProfile`, `MealEntry`)
- **Feature structure:** `features/<name>/domain/` (models) + `features/<name>/presentation/` (pages/widgets)
- **Prefix:** Shared UI components use `sn_` prefix (`sn_button.dart`, `sn_card.dart`, `sn_text_field.dart`)
- **Imports:** Absolute package imports (`package:smartnutri/...`)
- **Serialization:** Manual `toMap()` / `fromMap()` (no code generation)
- **Enums:** Dart 3 `switch` expressions with exhaustive matching
- **Linting:** `package:flutter_lints/flutter.yaml` (default Flutter lint rules)

## Common Gotchas

1. **PowerShell execution policy:** `firebase` CLI may be blocked → run `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
2. **Android SHA fingerprints:** SHA-1 & SHA-256 must be registered in Firebase Console for auth. Re-download `google-services.json` after changes.
3. **Firebase config cache:** Run `flutter clean && flutter run` if Firebase config changes don't take effect.
4. **Deploy ≠ data:** `firebase deploy --only firestore:rules,firestore:indexes` updates rules/indexes only, does NOT create data.
5. **AVD name case-sensitivity:** Copy exact name from `emulator -list-avds` output.
6. **Food catalog is in-memory:** `FoodService` contains ~120 items hard-coded in Dart. The Firestore `foods` collection exists in rules but is not yet populated.
7. **Legacy navigation:** `core/navigation/app_router.dart` is legacy tab config; active routing uses `go_router_config.dart`.
8. **Storage rules are open:** Current storage rules allow any authenticated user full read/write — tighten before production.
