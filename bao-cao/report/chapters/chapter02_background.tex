\chapter{Kiến thức nền tảng}

\section{Tổng quan về kiến trúc hệ thống}

SmartNutri được xây dựng theo mô hình \textbf{client-server} kết hợp với kiến trúc \textbf{ba tầng} (three-tier architecture), bao gồm:

\begin{itemize}
    \item \textbf{Tầng trình bày (Presentation Tier):} Ứng dụng di động Flutter và trang quản trị React — chịu trách nhiệm hiển thị giao diện người dùng và tương tác với người dùng cuối.
    \item \textbf{Tầng logic (Application Tier):} Firebase Cloud Functions và Google Gemini API — xử lý logic nghiệp vụ, xác thực, phân tích ảnh bằng AI.
    \item \textbf{Tầng dữ liệu (Data Tier):} Firebase Firestore (cơ sở dữ liệu NoSQL) và Firebase Storage (lưu trữ file) — chịu trách nhiệm lưu trữ và truy xuất dữ liệu.
\end{itemize}

Hệ thống sử dụng mô hình \textbf{MVC} (Model-View-Controller) trong ứng dụng Flutter để tách biệt giữa giao diện người dùng, logic xử lý và dữ liệu. Các API được thiết kế theo phong cách \textbf{RESTful}, sử dụng JSON làm định dạng trao đổi dữ liệu chính.

\section{Các công nghệ được sử dụng}

\subsection{Backend}

\subsubsection{Firebase}

Firebase là nền tảng phát triển ứng dụng của Google, cung cấp nhiều dịch vụ backend dưới dạng BaaS (Backend-as-a-Service). Trong dự án SmartNutri, Firebase được chọn làm backend chính vì các lý do sau:

\begin{itemize}
    \item \textbf{Firebase Authentication:} Cung cấp hệ thống xác thực người dùng sẵn có, hỗ trợ đăng nhập qua email/password và Google Sign-In. Giúp giảm thiểu thời gian phát triển phần xác thực và đảm bảo bảo mật theo chuẩn của Google.
    \item \textbf{Cloud Firestore:} Cơ sở dữ liệu NoSQL dạng document, hỗ trợ đồng bộ dữ liệu thời gian thực (real-time sync). Firestore phù hợp với cấu trúc dữ liệu linh hoạt của ứng dụng dinh dưỡng, nơi mỗi người dùng có cấu trúc dữ liệu nhật ký ăn uống khác nhau.
    \item \textbf{Firebase Storage:} Lưu trữ hình ảnh người dùng và ảnh món ăn được tải lên. Tích hợp chặt chẽ với Firebase Authentication để kiểm soát quyền truy cập.
    \item \textbf{Firebase Cloud Functions:} Môi trường serverless cho phép chạy code backend mà không cần quản lý máy chủ. Sử dụng để xử lý logic nghiệp vụ phức tạp mà không nên thực hiện ở phía client.
\end{itemize}

\subsubsection{Google Gemini API}

Gemini là mô hình ngôn ngữ lớn (LLM) đa phương thức của Google, có khả năng hiểu cả văn bản và hình ảnh. Trong SmartNutri, Gemini API được sử dụng để:

\begin{itemize}
    \item Nhận diện món ăn Việt Nam từ ảnh chụp.
    \item Ước lượng thành phần dinh dưỡng của món ăn.
    \item Gợi ý thực đơn dựa trên mục tiêu dinh dưỡng của người dùng.
    \item Trả lời câu hỏi về dinh dưỡng qua chatbot AI.
\end{itemize}

\subsection{Frontend}

\subsubsection{Flutter}

Flutter là framework phát triển ứng dụng đa nền tảng của Google, sử dụng ngôn ngữ Dart. Flutter được chọn cho SmartNutri vì:

\begin{itemize}
    \item \textbf{Đa nền tảng:} Một codebase duy nhất có thể chạy trên cả Android và iOS, tiết kiệm chi phí phát triển.
    \item \textbf{Hiệu năng cao:} Flutter biên dịch trực tiếp sang native code (ARM), không cần bridge như React Native, cho trải nghiệm mượt mà.
    \item \textbf{Hot Reload:} Cho phép xem thay đổi giao diện ngay lập tức trong quá trình phát triển.
    \item \textbf{Hệ sinh thái widget phong phú:} Flutter cung cấp bộ widget Material Design và Cupertino đầy đủ, giúp xây dựng giao diện đẹp và nhất quán.
\end{itemize}

\subsubsection{React (Admin Web)}

Trang quản trị SmartNutri được xây dựng bằng React 18 kết hợp với TypeScript và Vite:

\begin{itemize}
    \item \textbf{React:} Thư viện JavaScript phổ biến để xây dựng giao diện người dùng dạng SPA (Single Page Application), với hệ sinh thái component phong phú.
    \item \textbf{TypeScript:} Cung cấp kiểm tra kiểu tĩnh, giúp giảm lỗi runtime và tăng khả năng bảo trì code.
    \item \textbf{Vite:} Công cụ build hiện đại với thời gian khởi động nhanh và HMR (Hot Module Replacement).
\end{itemize}

\subsection{Các công nghệ bổ trợ khác}

\begin{itemize}
    \item \textbf{Git \& GitHub:} Quản lý phiên bản và lưu trữ mã nguồn.
    \item \textbf{Node.js:} Môi trường runtime cho Firebase Cloud Functions.
    \item \textbf{Android Emulator:} Môi trường kiểm thử ứng dụng trên máy ảo Android.
    \item \textbf{Firebase Emulator Suite:} Môi trường giả lập các dịch vụ Firebase trên local để phát triển và kiểm thử.
\end{itemize}
